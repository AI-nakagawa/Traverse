# 現場座標ノート

Xを北、Yを東、北を0度として時計回りに増加する方向角を採用した座標計算PWAです。2点を逆算して基準線を設定し、直線延長、右回り夾角による方向変更、左・右への平行線オフセットを計算できます。測線図上の線をタップして基準線を選択でき、方向反転にも対応しています。

座標CSVは見出しなしで、各行を左から `点名,X,Y` の順に読み込みます（例：`BP,1200.20,1000.233`）。書出しも見出しなしです。読込後は測線図の点を順番にタップして始点・終点を設定でき、入替や選択解除も可能です。

## GitHub Pages

このフォルダの中身をリポジトリ直下へ置き、Settings > Pages で main ブランチの `/ (root)` を公開してください。HTTPSの公開URLからPWAとしてインストールできます。

記録は端末内に保存されます。定期的にJSONバックアップを出力してください。PDF出力は端末の印刷画面から「PDFとして保存」を選びます。

# 現場座標ノート

Xを北、Yを東、北を0度として時計回りに増加する方向角を採用した座標計算PWAです。2点を逆算して基準線を設定し、直線延長、右回り夾角による方向変更、左・右への平行線オフセットを計算できます。測線図上の線をタップして、次の計算に使う基準線を選択できます。選択した基準線は方向を反転でき、矢印で現在の進行方向を確認できます。

## GitHub Pages

このフォルダの中身をリポジトリ直下へ置き、Settings > Pages で main ブランチの `/ (root)` を公開してください。HTTPSの公開URLからPWAとしてインストールできます。

記録は端末内に保存されます。定期的にJSONバックアップを出力してください。PDF出力は端末の印刷画面から「PDFとして保存」を選びます。
